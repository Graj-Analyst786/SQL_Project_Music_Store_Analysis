SQL_Project_Music_Store_Analysis
Project Overview:

This project analyzes a digital music store database using SQL to understand sales, customers, artists, albums, and music trends.

Tools Used:
PostgreSQL
SQL
pgAdmin 4

Key Analysis:
Customer and sales analysis
Top artists and tracks
Revenue analysis
Genre and album analysis
Customer spending insights

Objective:

To use SQL queries to find useful business insights from music store data and support data-driven decisions.
